# cofrinho-agregador-imposto-renda
# 📊 Agregador de Dados para Imposto de Renda em Excel

> Ferramenta interativa desenvolvida em Excel para centralizar, organizar e validar dados financeiros, facilitando o controle de entradas e a preparação de informações para a declaração de Imposto de Renda.

---

## 🚀 Sobre o Projeto

Este projeto foi desenvolvido como parte de um desafio/bootcamp na **DIO Academy**. O objetivo principal foi criar uma solução prática e automatizada no Excel para resolver uma dor recorrente: a dispersão de informações financeiras necessárias na hora de prestar contas com o Fisco.

A planilha funciona como um **agregador de dados centralizado**, permitindo que o usuário gerencie suas movimentações financeiras de forma eficiente, segura e com uma experiência de navegação fluida.

---

## ✨ Principais Funcionalidades

- **🧭 Menus de Navegação Intuitivos:** Estrutura organizada por abas e botões de acesso rápido que facilitam a movimentação entre os diferentes painéis da planilha.
- **🛡️ Validações Automáticas:** Regras de validação de dados aplicadas para evitar inconsistências, erros de digitação e garantir a integridade das informações inseridas.
- **📈 Controle Eficiente de Entradas:** Módulo dedicado ao registro e acompanhamento detalhado de receitas e aportes.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **Microsoft Excel** (Recursos avançados de validação de dados, fórmulas, formatação condicional e estruturação de interfaces).
